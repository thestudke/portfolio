# 怎么录案例视频（≤10 分钟）

站点这边已经支持两种形态，你先定成片长度再录：

| 形态 | 时长 | 弹层里的行为 | 配置 |
|---|---|---|---|
| 循环短片 | 6–15 秒 | 自动播放、静音、循环、无控件 | `video: { src, duration: 9 }` |
| 长演示 | 1–10 分钟 | 不自动播，点原生播放条才开始；带时长标签 | `video: { src, duration: 420, autoplay: false }` |

判定规则写死在 `src/components/CaseDetail.jsx`：`duration > 30` 或显式 `autoplay: false` 就走长视频模式。

## 一、录之前：把「能演示的东西」跑起来

录屏最怕录到「正在输入…」和报错弹窗。开始前先确认：

1. 后端在跑、前端能出结果（用同一份数据，别用现场输入的新问题赌一次 API 调用）
2. 浏览器缩放固定 100%，窗口 1600×900 或 1920×1080
3. 关掉 QQ / 微信 / 邮件通知，隐藏书签栏（`Ctrl+Shift+B`）
4. 桌面壁纸换成纯色，任务栏自动隐藏
5. 录之前先完整走一遍流程，把要展示的答案先「预热」一次（很多 RAG 首问很慢）

## 二、工具与参数

- **Windows 自带**：`Win + G` → 捕获 → 录制。简单，但只能录单窗口、无区域选择。
- **OBS**（推荐）：显示捕获 → 输出 1920×1080 / 30fps / CQP 23 / 关键帧 2 秒；音频轨直接关掉（我们要无声）。
- **PowerPoint 录屏**：插入 → 屏幕录制，适合只录一小块区域。

不管用哪个，**录的时候就按无声录**：不要录麦克风，后面能省一半体积。

## 三、6 分钟分镜（企业年报 RAG）

| 时间 | 画面 | 旁白要点（写在页面上当字幕，别配音） |
|---|---|---|
| 0:00–0:20 | 打开首页，鼠标停住 | 一句话说清这是什么：把年报变成能追问、能指页码的问答 |
| 0:20–1:20 | 问第一个问题，等答案出来 | 强调答案末尾的「第 7 页」——这就是溯源 |
| 1:20–2:20 | 点开引用，跳到 PDF 对应页 | 证明不是编的：页码能对上原文 |
| 2:20–3:20 | 问一个跨页表格的问题 | 说明父子块 + 表头指纹合并，为什么跨页不会答错 |
| 3:20–4:20 | 问一个文档里没有的问题 | 展示「没找到就说没找到」，这比答对更能证明可靠 |
| 4:20–5:20 | 切工具开关，看回答变化 | 展示 8 种工具装配不是 PPT 里的概念 |
| 5:20–6:00 | 回到首页收尾 | 一句总结 + 屏幕上留着项目名 |

要点：
- 每个动作之后**停 1–2 秒**再动，录屏最容易犯的错是一直在动，剪都没法剪
- 鼠标移动走直线、慢一点；不要画圈找按钮
- 任何一步超过 20 秒的空等，就剪掉（或用 1.5 倍速）

## 四、录完之后

1. **压到 8–30 MB**：1080p / 30fps / H.264 / CRF 23 大约是 1 分钟 8–12 MB。用 HandBrake（免费）或 ShanaEncoder，预设「Fast 1080p30」，音频轨删掉。
2. **抽封面**（不需要 ffmpeg）：

   ```powershell
   cd C:\Users\asus\OneDrive\桌面\作品集\site
   node scripts/poster-from-video.mjs public/media/02-rag.mp4 public/thumbs/02-rag.png 3
   ```

3. **接线**（`src/data.js`，项目 02 的 `detail`）：

   ```js
   video: {
     src: '/media/02-rag.mp4',
     poster: '/thumbs/02-rag.png',
     duration: 372,        // 秒，用来判定长视频模式并显示 6:12
     autoplay: false,      // 长视频必须关掉自动播
     caption: '产品演示',
   },
   ```

4. `npm run build`，刷新页面 → 点项目 02 的「查看案例详解」→ 左侧应该是封面 + 播放条。

## 五、两个坑

- **10 分钟不是越长越好**。招聘方平均在一个作品上停 40–90 秒；超过 3 分钟的视频，实际看完率个位数。建议弹层放 1–3 分钟的「精华版」，完整版另存一个链接（B 站 / 网盘）放在 `detail.blocks` 里。
- **MediaRecorder 合成的 webm 没有时长头**：浏览器播到缓冲完才解析出 `duration`，播放条一开始会显示异常。真机录屏（mp4）不会有这个问题；非要用 webm，就用 ffmpeg 重新封装一次 `-c copy`。

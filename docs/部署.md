# 部署到哪里

站点是纯静态的（`dist/` = 一个 HTML + 一个 JS + 一个 CSS + 图片 + 两个 mp4，共 36 MB），
没有任何后端、没有数据库，所以凡是「能把文件夹挂到网上」的服务都能放。

## 结论先放

| 方案 | 免费额度 | 国内访问 | 备案 | 适合 |
| --- | --- | --- | --- | --- |
| **GitHub Pages** | 1 GB 仓库 / 100 MB 单文件 / 100 GB 流量每月 | 一般，偶发打不开 | 不需要 | 首选：和简历上的 GitHub 同域，零成本 |
| **Vercel** | 100 GB 流量每月 | 一般，电信/联通好些 | 不需要 | 想要 `xxx.vercel.app` 或绑自己域名 |
| **Cloudflare Pages** | 不限流量 | **不稳**，经常超时 | 不需要 | 海外投递或备线 |
| **腾讯云 EdgeOne Pages** | 有免费额度，需实名 | **快** | 绑自定义域名要备案 | HR 全在国内、要稳 |
| **阿里云 OSS + CDN** | 按量计费（几块钱/月） | **快** | 必须备案 | 有域名、愿意等 20 天 |

**推荐路径**：先 GitHub Pages 上线（十分钟、零成本），拿到简历能用的链接；
如果你后面买了域名、想让国内 HR 打开更快，再迁 EdgeOne Pages 或 Vercel 绑域名。

## 一、GitHub Pages（已配好，直接推）

仓库里的 `.github/workflows/deploy.yml` 已经写好：推 `main` 就自动构建并发布，
`BASE_PATH` 自动取仓库名（项目站点是 `https://<用户名>.github.io/<仓库名>/`，路径不能写死 `/`）。

```powershell
cd C:\Users\asus\OneDrive\桌面\作品集\site
# 1. 先在 GitHub 网页上建一个空仓库，例如 portfolio（public，不要勾 README）
git remote add origin https://github.com/thestudke/portfolio.git
git push -u origin main
```

然后：仓库 **Settings → Pages → Build and deployment → Source 选 `GitHub Actions`**。
推送完成后 Actions 跑完大约 1 分钟，地址是：

```
https://thestudke.github.io/portfolio/
```

- 这个仓库已经 `git init` 且提交过一次（62 个文件，含两个视频），你只需要 `remote add` + `push`。
- 以后改内容：`git add -A; git commit -m '...'; git push`，自动重新部署。
- 仓库超过 1 GB 或单文件超 100 MB 会被拒；现在 31.8 MB 的 mp4 是安全的。

## 二、Vercel（不改任何配置）

1. https://vercel.com 用 GitHub 登录 → **Add New → Project** → 选 `portfolio` 仓库。
2. Framework 自动识别为 Vite；Build Command `npm run build`，Output `dist`，直接 Deploy。
3. 得到 `https://portfolio-xxxx.vercel.app`。想换域名：Project → Settings → Domains。

Vercel 部署的是根路径 `/`，所以**不要**设 `BASE_PATH`（工作流只给 GitHub Pages 用）。

## 三、自己域名 + 国内加速（进阶）

1. 买域名（`.com` 约 ¥60/年；`.cn` 需实名）。
2. 国内节点（EdgeOne / 阿里云 OSS）绑域名要先 **ICP 备案**，福建个人备案约 7–20 个工作日，
   要身份证、居住证/学生证、域名证书。
3. 备案下来后把 `dist/` 传到对象存储静态站点，绑域名 + 开 HTTPS + 开 CDN。
4. 若挂在 Vercel / Cloudflare 上，不需要备案（服务器在境外），代价是国内访问速度看线路。

## 四、几件容易踩的事

- **不要用 `file://` 双击打开 `dist/index.html`**：`type="module"` 脚本会被 CORS 拦掉，页面空白。
- 视频是懒加载的（`preload="metadata"`），但点播放会拉 31.8 MB。手机流量环境体验一般，
  可以把长视频另外传 B 站，弹层里只留 0:30 那条。
- 简历 / 邮件里别放 `192.168.x.x` 这种内网地址，也别直接发 `dist` 压缩包（36 MB）。
- 换域名后记得回来改 `index.html` 里的 `<meta property="og:url">`（如果以后加分享卡片）。
